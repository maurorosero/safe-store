# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: se discute sobre el código, no sobre las personas. No se toleran
insultos, acoso ni descalificaciones. Quien modera puede cerrar una discusión
o bloquear a alguien que insista.

Para reportar: abrí un issue privado en las advertencias de seguridad del repo
o escribí a mauro@rosero.one.
